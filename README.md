## I'm yungnoodleex 👋

Coffee, code, repeat.

Hey, I'm yungnoodleex — I build frontend things with React, Next.js, and TypeScript, then obsess over whether they load fast enough. Most of my time goes into design systems, accessible components, and convincing myself that this is the last time I'll refactor my Tailwind config.
